## File Management

- [fd](https://github.com/sharkdp/fd) - Fast alternative to find
- [exa](https://github.com/ogham/exa) - Modern ls replacement
- [bat](https://github.com/sharkdp/bat) - Cat with syntax highlighting
- [dust](https://github.com/bootandy/dust) - Intuitive disk usage
- [broot](https://github.com/Canop/broot) - Navigate directories
- [zoxide](https://github.com/ajeetdsouza/zoxide) - Smarter cd
- [yazi](https://github.com/sxyazi/yazi) - Blazing fast terminal file manager written in Rust with async I/O, image previews, and a Lua plugin system
- [superfile](https://github.com/yorukot/superfile) - Pretty fancy and modern terminal file manager with a polished multi-panel UI

## Text Processing

- [ripgrep](https://github.com/BurntSushi/ripgrep) - Fast grep alternative
- [sd](https://github.com/chmln/sd) - Intuitive sed replacement
- [jq](https://github.com/stedolan/jq) - JSON processor
- [yq](https://github.com/mikefarah/yq) - YAML processor
- [fzf](https://github.com/junegunn/fzf) - Fuzzy finder
- [choose](https://github.com/theryangeary/choose) - Cut alternative
- [jc](https://github.com/kellyjonbrazil/jc) - Convert the output of popular CLI tools and file types to JSON/YAML (JSONifies `ls`, `dig`, `ps`, and hundreds more)
- [dasel](https://github.com/TomWright/dasel) - Query and modify JSON/YAML/TOML/XML data using a single selector syntax
- [gron](https://github.com/tomnomnom/gron) - Make JSON greppable by flattening it into discrete assignments

## Network

- [httpie](https://github.com/httpie/httpie) - HTTP client
- [curlie](https://github.com/rs/curlie) - Curl with httpie interface
- [dog](https://github.com/ogham/dog) - DNS client
- [bandwhich](https://github.com/imsnif/bandwhich) - Bandwidth monitor
- [gping](https://github.com/orf/gping) - Ping with graph

## Development

- [delta](https://github.com/dandavison/delta) - Git diff viewer
- [lazygit](https://github.com/jesseduffield/lazygit) - Git TUI
- [gitui](https://github.com/extrawurst/gitui) - Blazing fast terminal UI for git written in Rust
- [jj](https://github.com/jj-vcs/jj) - Jujutsu, a Git-compatible version control system with automatic rebasing, first-class conflicts, and an undoable operation log
- [gh](https://github.com/cli/cli) - GitHub CLI
- [tokei](https://github.com/XAMPPRocky/tokei) - Code statistics
- [hyperfine](https://github.com/sharkdp/hyperfine) - Benchmarking

## System

- [btop](https://github.com/aristocratos/btop) - Resource monitor
- [procs](https://github.com/dalance/procs) - Modern ps
- [bottom](https://github.com/ClementTsang/bottom) - System monitor
- [duf](https://github.com/muesli/duf) - Disk usage
- [tldr](https://github.com/tldr-pages/tldr) - Simplified man pages

## Shell & Productivity

- [atuin](https://github.com/atuinsh/atuin) - Magical shell history with SQLite storage, full-text search, and encrypted cross-machine sync
- [zellij](https://github.com/zellij-org/zellij) - A terminal workspace (multiplexer) with batteries included and a friendly layout system
